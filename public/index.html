NixNet

NixNet is Fred Nix's private GPU lab for a small circle of friends: browser chat and an OpenAI-compatible API over Tailscale, paired with shared NAS storage and short-lived agent sandboxes on the same homelab.

Not a product launch. A working homelab with a name, built so friends can think and build without renting someone else's GPU.

>_ hex: 128GB GPU box

01

The GPU box and what friends get

NixNet runs on Fred's Proxmox host, hex: a Minisforum MS-S1 MAX powered by an AMD Ryzen AI MAX+ 395 (16 cores / 32 threads), 128 GB of unified memory (about 123 GiB usable), a Radeon 8060S iGPU (80 GiB GPU memory limit), and an integrated NPU.

Friends already on Fred's Tailscale mesh open a browser chat (Open WebUI 0.13.3) or point any OpenAI-compatible client at the API.

What friends get once invited:

  • Browser chat

    Browser chat with presets (chat, code, see, facts, glm-4.7-flash, NixNet AI) and personas (researcher, artist, coder, vision, nixnet-help).

  • Local inference

    Local inference via Ollama (0.40.16), keeping up to two models resident at a time across reasoning, coding, vision, and fast helper models (such as gpt-oss:120b, qwen3-coder:30b, qwen3.6:35b, gemma4, qwen3-vl, and more).

  • Images, media, search

    Image and media generation (ComfyUI with FLUX.1 schnell, LTX-Video, ACE-Step 1.5, plus MOSS-Image) and web search from the Integrations menu.

  • Your own API key

    A personal API key and OpenAI-compatible base URL, plus a live status line and light usage leaderboard on the friends welcome page.

! Access stays strictly on the tailnet. There is no public signup, and the friends welcome site stays tailnet-only.

03

Agent sandboxes HyperNix and short-lived linux containers

On hex, a HyperNix control plane runs with isolated guest networking, alongside a live spawn broker (hex.sessions) that spins up short-lived linux containers for agent work from prebuilt templates and reaps them automatically when a task finishes or its TTL expires. HyperNix's rule is simple: local models only propose NixOS configs, nix evaluation proves every proposal before Fred approves it, and agent sessions stay sandboxed away from the friends chat stack.

04

How it fits together

Friends reach NixNet over a private Tailscale mesh with zero open public ports. Chat, local models, and the API run on hex. The nas holds shared project and session data on tank over NFS. HyperNix and the hex.sessions spawn broker run isolated short-lived linux containers beside that stack. A self-hosted Infisical secrets vault on the same Tailscale mesh keeps API keys and credentials off random disks and out of chat.
