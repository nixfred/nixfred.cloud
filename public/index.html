03

A private AI workspace what your people get in the browser

Open WebUI 0.13.5, signed in through Tailscale so nobody juggles passwords. A fair round-robin queue shares the GPU, so a heavy job never locks anyone out.

  • Auto picks the model

    Auto is the default. It reads each message and sends it to the right local model for code, images, quick chat, deep reasoning or documents. Every model lists a speed measured on this machine.

  • Chat with your documents

    Upload files once into a knowledge collection and ask questions. Answers cite their sources, and you can click through to the evidence beside the reply.

  • Talk to it

    Hands-free voice chat. Speech to text and the spoken reply both run on the server, so it works the same on a phone.

  • Images, video and music

    FLUX.1 schnell and MOSS-Image through ComfyUI 0.43.0, short clips with LTX-Video, and songs up to 2 minutes with ACE-Step 1.5. All local.

  • Web search with sources

    Models search the web through a private search service on the box and cite where each claim came from.

  • Code that runs

    The model writes Python and runs it for math, data and charts, on a separate little computer with no internet and no access to anything else.

  • Use a remote computer from chat

    Connect a machine to chat and work with its files and command line beside the conversation. On NixNet it is shared with the owner's account only, and every other account is denied.

  • Teamwork built in

    Side chats, comment threads on any reply, an inbox for mentions, and folder workspaces that keep project chats, files and notes together.

04

Built for developers and agents

Apps and AI agents get the same private box through standard interfaces. Point any OpenAI-style client at it by changing one URL.

  • OpenAI-compatible API

    Same shape as OpenAI, including tool calls through the Auto model, streaming or not. Each person makes their own key, so usage stays tied to the person.

  • Agent keys

    A stand-in key per agent, with a label, scopes and an expiry. Revoke it in one step. The real key never leaves home.

  • MCP server with 19 tools

    Agents get models, chat, images, web search, speech, usage, status, the queue, sandboxes and agent keys as tools.

  • Offline sandboxes

    An agent borrows its own linux box with no internet and no access to anyone else, cleaned up automatically. Persistent workspaces keep files between sessions, with restore points to roll back to.

05

Storage, backups and operations

A dedicated nas guest on hex keeps the ZFS pool tank for shared projects, sessions and scratch space, shared over NFS and SMB.

Proxmox Backup Server takes nightly, deduplicated backups and keeps four copies: the primary store, an 8TB vault, a removable grab-and-go drive and an offsite copy in the cloud. Restores are written down and tested.

Every upgrade starts with a snapshot, every change lands in a change log, and API keys and credentials live in a self-hosted Infisical secrets vault instead of on random disks. Watchdogs send mail when a backup goes stale.

06

How it fits together

Your people and their agents reach the stack over a private Tailscale mesh with zero open public ports. Chat, the API and MCP run on hex. The nas holds shared data on tank. Sandboxes and the hex.sessions broker run short-lived linux containers beside the stack. Secrets sit in a vault, and everything is backed up nightly with an offsite copy.
