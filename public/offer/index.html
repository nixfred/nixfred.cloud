02

What's included every item runs on the NixNet reference build today

  • Private multi-user chat. Open WebUI in the browser, signed in through a private encrypted mesh, so nobody juggles passwords. Chat with your documents, with answers that cite their sources.
  • An OpenAI-compatible API. Any app or agent you already use points at your box by changing one URL. Each person makes their own key, so usage stays tied to the person.
  • Model auto-routing with measured speeds. Auto reads each message and sends it to the right local model. Every model lists a speed measured on your machine, and a fair queue shares the GPU, so a heavy job never locks anyone out.
  • Image, voice and video. Image generation through ComfyUI, short video clips, and hands-free voice chat with speech running on the server. All local.
  • Agent sandboxes. An agent borrows its own linux box with no internet and no access to anyone else, cleaned up automatically, with the walls tested every night.
  • ZFS storage. A ZFS pool for shared projects and scratch space, shared over NFS and SMB.
  • Nightly backups with an offsite copy. Proxmox Backup Server takes nightly, deduplicated backups, with an offsite copy. Every upgrade starts with a snapshot.
  • Tailscale-only access. Everything is reached over a private Tailscale mesh with zero open public ports.
  • Docs. A handoff document for your team, including the checks the build has to pass.
  • One training session for your team, on a call.
